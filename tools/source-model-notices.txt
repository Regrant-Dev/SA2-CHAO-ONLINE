Creature importer format references

The importer's model, texture and motion code (src/creature/asset_import.rs and
the readers it uses) was written with reference to gdkchan/SPICA,
https://github.com/gdkchan/SPICA, including its GF model, mesh, material,
texture, skeletal motion, PICA command, float24 and ETC1 readers.
SPICA is released under the Unlicense/public-domain dedication below.

This notice covers format-reading code, not game assets.
No copyrighted game assets are part of this repository or its release package.
